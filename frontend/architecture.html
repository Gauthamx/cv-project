System Architecture

How CampusVision works under the hood

📷 1. Camera Module

Captures real-time video feeds from strategic points in the library and parking areas.

⚙️ 2. Image Processing Module

Uses OpenCV (Python) to preprocess captured frames, apply filters, and resize images for optimal AI inference.

🧠 3. Object Detection Module

A trained YOLO (You Only Look Once) model analyzes the processed frames to detect whether predefined ROI (Regions of Interest) representing seats or parking spaces are vacant or occupied.

📊 4. Occupancy Analysis Module

Calculates the overall occupancy percentage and formats the data for the backend API.

🗄️ 5. Database Module

Stores real-time status and historical occupancy records securely in MongoDB. Powered by Mongoose.

🌐 6. Backend API Module

A fast Node.js and Express server that processes requests, validates data updates from the vision system, and serves live occupancy data via RESTful API endpoints.

📱 7. CampusVision Web App

The frontend application built with HTML5, CSS3, and JavaScript. It provides an intuitive dashboard for students and staff to view real-time resource availability.
